## Key Architecture Decisions

1. **pnpm** — Faster, stricter than npm/yarn for monorepos
2. **App Router** — Next.js 14+ recommended routing approach
3. **Route Groups** — `(auth)`, `(dashboard)`, `(public)`, `(super-admin)` for layout separation
4. **Module-per-feature** — NestJS modules self-contained with controller + service + DTOs
5. **Prisma at API level** — Schema lives in `apps/api/prisma/`, types shared via `packages/shared`
6. **Docker Compose** — Local dev DB without installing PostgreSQL/Redis on machine
