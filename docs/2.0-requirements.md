# BookMyTurf — Product Requirements Document (2.0)

## 1. Product Vision

**Product Name:** BookMyTurf
**Tagline:** India's sports turf booking & management platform
**Type:** Multi-tenant SaaS (B2B2C)
**Business Model:** Hybrid (Subscription fee from turf owners + Commission per online booking)

### Problem Statement

Sports turf owners in India manage bookings manually (phone calls, WhatsApp messages, paper registers). This leads to:

- Double bookings and scheduling conflicts
- No visibility into peak hours or revenue trends
- Walk-in customers not tracked
- No online presence for customer discovery
- Staff cannot manage independently without owner

### Solution

A platform where turf owners get a complete digital booking system (admin dashboard + public booking page) and customers can discover, browse, and book turf slots online.

### Target Users

| User             | Description                                             |
| ---------------- | ------------------------------------------------------- |
| **Turf Owner**   | Business owner who owns/operates sports turf facilities |
| **Turf Manager** | Hired staff managing day-to-day operations              |
| **Turf Staff**   | Ground-level staff (check-in, maintenance)              |
| **Customer**     | End-user who books and plays at turfs                   |
| **Super Admin**  | Platform operator (you) managing the entire SaaS        |

### Target Market

- **Geography:** India (metro + tier-1/2 cities)
- **Language:** English (i18n ready for Hindi/regional)
- **Currency:** INR
- **Primary Sports:** Cricket, Football, Badminton, Futsal, Box Cricket

## 3. Revenue Model

### Subscription Tiers

| Plan       | Monthly | Annual  | Commission | Limits                          |
| ---------- | ------- | ------- | ---------- | ------------------------------- |
| Starter    | ₹999    | ₹9,990  | 8%         | 3 venues, 5 courts, 3 staff     |
| Pro        | ₹2,499  | ₹24,990 | 5%         | 10 venues, 25 courts, 10 staff  |
| Enterprise | ₹4,999  | ₹49,990 | 3%         | Unlimited venues, courts, staff |

### Commission

- Charged only on online bookings (customer pays via Razorpay)
- Walk-in bookings: no commission (turf owner collected payment directly)
- Commission deducted from turf owner's payout (customer sees all-inclusive price)

### Free Trial

- 14-day free trial on signup (Pro plan features)
- No credit card required to start
- Trial expires → downgrade to read-only until subscription activated

## 6. Constraints & Assumptions

### Constraints

- Solo developer + AI — no dedicated QA or DevOps
- Budget: Minimize hosting costs (AWS free tier first year)
- Timeline: 10 weeks to MVP
- India-only market for MVP (INR, IST timezone)

### Assumptions

- Turf owners have smartphones and basic tech literacy
- Customers are comfortable with UPI/online payments
- WhatsApp Business API approval takes 1-2 weeks
- Razorpay account activation takes 2-3 business days
- Turf owners will adopt digital booking if onboarding is simple

## 7. Out of Scope (MVP)

These features are explicitly excluded from MVP and tracked in post-launch backlog:

| Feature                                       | Reason                                  | Phase   |
| --------------------------------------------- | --------------------------------------- | ------- |
| Dynamic pricing (auto-adjust based on demand) | Needs booking history data first        | Phase 2 |
| Membership packages (monthly passes)          | Added complexity, validate demand first | Phase 2 |
| Reviews & ratings                             | Needs customer volume first             | Phase 2 |
| Referral/loyalty programs                     | Growth feature, not core                | Phase 2 |
| React Native mobile app                       | PWA sufficient for launch               | Phase 2 |
| Custom domain per tenant                      | Premium feature, low priority           | Phase 2 |
| Multi-language UI (Hindi)                     | i18n ready, translations added later    | Phase 2 |
| Tournament/league management                  | Niche feature, not core booking         | Phase 3 |
| Inventory management (equipment rental)       | Separate domain                         | Phase 3 |

## 8. Success Criteria (MVP Launch)

MVP is considered successful when:

- [ ] Turf owner can register → onboard → configure venue/courts/slots
- [ ] Customer can browse → select slots → pay → receive confirmation
- [ ] Walk-in bookings can be created by staff
- [ ] Cancellation + refund works per policy
- [ ] Analytics dashboard shows meaningful data
- [ ] Notifications delivered via WhatsApp + Email
- [ ] Platform deployed on AWS with CI/CD
- [ ] 5 real turf owners onboarded and actively using the system
