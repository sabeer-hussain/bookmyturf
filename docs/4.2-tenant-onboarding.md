# BookMyTurf — Tenant Onboarding Documentation (4.2)

## Overview

Tenant onboarding flow for turf owners to register, set up their business, and access the dashboard.

- **Onboarding:** Self-serve, no approval needed
- **Trial:** 14-day free trial on Starter plan
- **Tenant isolation:** AsyncLocalStorage + Prisma middleware

---

## API Endpoints

### 1. POST /v1/tenants/onboard

**Purpose:** Complete tenant onboarding — creates tenant, links user, starts trial.

**Auth:** Required (any authenticated user without a tenant)

**Request:**
| Field | Type | Required | Description |
|-------|------|----------|-------------|
| name | string | Yes | Business name (max 100 chars) |
| slug | string | Yes | URL slug (3-50 chars, lowercase, alphanumeric + hyphens) |
| phone | string | Yes | Business phone |
| email | string | Yes | Business email |
| address | string | No | Street address |
| city | string | No | City |
| state | string | No | State |
| pincode | string | No | PIN code |
| latitude | number | No | GPS latitude |
| longitude | number | No | GPS longitude |

**What happens internally:**

1. Validates slug format and uniqueness
2. Checks user doesn't already belong to a tenant
3. Creates tenant record
4. Updates user: sets tenantId + role = TURF_OWNER
5. Finds first active plan → creates Subscription (status: TRIAL, 14-day expiry)
6. Returns created tenant

**Response (201):**

```json
{
  "success": true,
  "data": {
    "id": "clx...",
    "name": "SportArena",
    "slug": "sportarena",
    "phone": "+919876543210",
    "email": "owner@sportarena.com",
    "city": "Mumbai",
    "state": "Maharashtra",
    "isActive": true,
    "onboardingComplete": true,
    "createdAt": "..."
  }
}
```

**Error responses:**
| Code | Condition |
|------|-----------|
| 400 | Slug already taken |
| 400 | User already belongs to a tenant |
| 400 | Validation errors (invalid slug format, missing fields) |
| 401 | Not authenticated |

### 2. GET /v1/tenants/slug/:slug

**Purpose:** Check if a slug is available.

**Auth:** Public

**Response (200):**

```json
{ "success": true, "data": { "available": true, "slug": "my-turf" } }
```

---

### 3. GET /v1/tenants/:id

**Purpose:** Get tenant details.

**Auth:** Required (tenant owner or super admin)

**Response (200):** Full tenant object.

**Error:** 403 if user doesn't own this tenant (and isn't super admin). 404 if not found.

---

### 4. PATCH /v1/tenants/:id

**Purpose:** Update tenant details.

**Auth:** Required (tenant owner or super admin)

**Request:** Any fields from `UpdateTenantDto` (name, phone, email, logo, address, city, state, pincode, latitude, longitude).

---

### 5. DELETE /v1/tenants/:id

**Purpose:** Deactivate tenant (soft delete).

**Auth:** Required (super admin only)

**Effect:** Sets `isActive = false`. Tenant data preserved.

## Tenant Isolation

### How It Works

```
Request → TenantMiddleware → AsyncLocalStorage.run({tenantId}) → Controller → Service → Prisma
                                                                                          ↓
                                                                          Prisma $use middleware reads
                                                                          tenantId from AsyncLocalStorage
                                                                          and auto-injects into queries
```

### Implementation

- **AsyncLocalStorage** — per-request context, no shared state between concurrent requests
- **Prisma `$use` middleware** — intercepts all queries for tenant-scoped models
- **Scoped models:** Venue, Court, Booking, Slot, CourtSport
- **Non-scoped models:** User, Tenant, Plan, Subscription (accessed cross-tenant)

### What the middleware does per action:

| Action               | Injection                  |
| -------------------- | -------------------------- |
| findMany / findFirst | Adds `where: { tenantId }` |
| create               | Adds `data: { tenantId }`  |
| update / updateMany  | Adds `where: { tenantId }` |
| delete / deleteMany  | Adds `where: { tenantId }` |

### Security layers:

1. **TenantMiddleware** — extracts `X-Tenant-Id` header into AsyncLocalStorage
2. **TenantGuard** — validates user's JWT tenantId matches request tenantId (per-route)
3. **Prisma middleware** — auto-filters queries (safety net even if guard is missed)
4. **Service-level checks** — explicit authorization in business logic

## Slug Rules

| Rule       | Validation                                   |
| ---------- | -------------------------------------------- |
| Format     | Lowercase letters, numbers, hyphens only     |
| Pattern    | `^[a-z0-9]+(?:-[a-z0-9]+)*$`                 |
| Length     | 3–50 characters                              |
| Uniqueness | Checked against database                     |
| Examples   | `sportarena`, `turf-99`, `my-cricket-ground` |
| Invalid    | `Sport_Arena`, `my turf`, `-start`, `end-`   |

## Onboarding Flow

```
User registers (OTP) → role: CUSTOMER
         ↓
User clicks "Set up my turf" → POST /tenants/onboard
         ↓
Tenant created → User role: TURF_OWNER → Subscription: TRIAL (14 days)
         ↓
User redirected to dashboard
```

## User Profile API

### GET /v1/users/:id

**Purpose:** Get user profile.

**Auth:** Required (self or super admin)

**Response:** User object without refreshToken.

**Errors:** 403 if accessing another user's profile. 404 if not found.

---

### PATCH /v1/users/:id

**Purpose:** Update own profile.

**Auth:** Required (self or super admin)

**Updatable fields:** firstName, lastName, avatar, gender (MALE/FEMALE/OTHER)

**Errors:** 403 if updating another user. 404 if not found.

## File Upload Service

### POST /v1/uploads/presigned

**Purpose:** Get a presigned URL for file upload.

**Auth:** Required

**Request:**
| Field | Type | Required | Values |
|-------|------|----------|--------|
| fileName | string | Yes | e.g., "logo.png" |
| fileType | string | Yes | image/jpeg, image/png, image/webp |
| folder | string | Yes | avatars, logos |

**Response:**

```json
{ "success": true, "data": { "uploadUrl": "...", "fileUrl": "..." } }
```

**Validation:**

- File type must be jpeg, png, or webp
- Max file size: 5MB (enforced client-side + presigned URL expiry)
- Folder must be "avatars" or "logos"

### Provider Pattern

| Provider | Env Var               | Behavior                                                   |
| -------- | --------------------- | ---------------------------------------------------------- |
| `dev`    | `UPLOAD_PROVIDER=dev` | Saves to local `/uploads` directory, returns localhost URL |
| `s3`     | `UPLOAD_PROVIDER=s3`  | Generates S3 presigned PUT URL, returns CloudFront URL     |

### Upload Flow

```
Frontend → POST /uploads/presigned → gets uploadUrl + fileUrl
Frontend → PUT uploadUrl (with file binary) → file uploaded
Frontend → PATCH /users/:id { avatar: fileUrl } → profile updated
```
