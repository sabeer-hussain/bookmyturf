```
┌─────────────────────────────────────────────────────────────┐
│                     REQUEST LIFECYCLE                         │
└─────────────────────────────────────────────────────────────┘

  Request → [Helmet] → [CORS] → [Rate Limiter]
                                       │
                                       ▼
                              [Tenant Middleware]
                              Extract tenantId from JWT
                                       │
                                       ▼
                              [Auth Guard]
                              Verify JWT validity
                                       │
                                       ▼
                              [Role Guard]
                              Check user role permission
                                       │
                                       ▼
                              [Tenant Guard]
                              Verify user belongs to tenant
                                       │
                                       ▼
                              [Controller]
                              Handle request
                                       │
                                       ▼
                              [Service Layer]
                              Business logic
                                       │
                                       ▼
                              [Prisma + Tenant Middleware]
                              Auto-inject WHERE tenantId = ?
                                       │
                                       ▼
                              [PostgreSQL]
                              Query with tenant isolation
```

## Scheduled Jobs (Cron Tasks)

Implemented via NestJS `@nestjs/schedule` (runs inside App Runner instance).

| Job | Schedule | Purpose |
|-----|----------|---------|
| `ExpireHeldBookings` | Every 1 minute | Release slots where `heldUntil < now()` and status = PENDING (10-min hold expired) |
| `BookingReminder` | Every 15 minutes | Send WhatsApp/Email reminder 1 hour before slot start time |
| `TrialExpiryNotification` | Daily at 9 AM | Notify tenants whose trial expires in 3 days / 1 day |
| `ExpireTrialSubscriptions` | Daily at midnight | Mark subscriptions as EXPIRED where `trialEndsAt < now()` |
| `DailyRevenueReport` | Daily at 8 AM | Email daily revenue summary to turf owners (optional preference) |
| `CleanupExpiredOTPs` | Every 30 minutes | Delete OTPs older than 10 minutes |

```typescript
// Example: apps/api/src/modules/scheduler/scheduler.service.ts
@Injectable()
export class SchedulerService {
  @Cron(CronExpression.EVERY_MINUTE)
  async expireHeldBookings() {
    await this.bookingsService.expireHeldBookings();
  }

  @Cron('0 */15 * * * *') // Every 15 min
  async sendBookingReminders() {
    await this.notificationsService.sendUpcomingReminders();
  }

  @Cron(CronExpression.EVERY_DAY_AT_MIDNIGHT)
  async expireTrials() {
    await this.subscriptionsService.expireTrials();
  }
}
```
