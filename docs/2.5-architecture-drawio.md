### CI/CD Flow (separate diagram)

```
┌──────────┐     ┌──────────────┐     ┌──────────────┐     ┌──────────┐
│  GitHub  │────►│GitHub Actions │────►│  Build &     │────►│   AWS    │
│  (push)  │     │  (trigger)   │     │  Test        │     │ (deploy) │
└──────────┘     └──────────────┘     └──────────────┘     └──────────┘

Pipeline Steps:
1. Install dependencies (pnpm)
2. Lint (ESLint)
3. Type-check (tsc)
4. Unit tests (Jest)
5. Integration tests (Supertest)
6. Build apps (Turborepo)
7. Deploy API → App Runner (Docker)
8. Deploy Web → Amplify (git push)
9. E2E tests (Playwright)
```
