# BookMyTurf — Sprint Plan (2.4)

## Overview

- **Total Duration:** 10 weeks (70 days)
- **Team:** Solo developer + AI assistance
- **Sprint Length:** 1 week
- **Working Days:** 6 days/week
- **Daily Hours:** 6-8 hours focused development

---

## Sprint Roadmap

```
Week 1-2: Foundation (Project Setup + Auth + Tenant)
Week 3-4: Core Domain (Venues, Courts, Sports, Slots)
Week 5-6: Booking Engine (Booking + Payments + Availability)
Week 7-8: Operations (Notifications, Analytics, Staff, Cancellation)
Week 9:   Admin & Polish (Super Admin, PWA, i18n, UI polish)
Week 10:  Testing, Deployment, Launch Prep
```

---

## Risk Mitigation

| Risk | Impact | Mitigation |
|------|--------|------------|
| Razorpay integration delays | High | Start integration in Sprint 5 Day 1, use test mode early |
| WhatsApp Business API approval | Medium | Apply for API access in Week 1, use email as fallback |
| AWS setup complexity | Medium | Use Amplify + App Runner (simplified), not raw ECS |
| Scope creep | High | Strict MVP boundary — anything not in Sprint 1-10 goes to backlog |
| Solo developer burnout | Medium | 6-day weeks (not 7), 6-8 hrs/day (not 12+) |
