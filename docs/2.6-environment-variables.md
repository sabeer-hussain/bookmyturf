# BookMyTurf — Environment Variables (2.6)

## All Required Environment Variables

### apps/api/.env

```bash
# ─────────────────────────────────────────────
# APPLICATION
# ─────────────────────────────────────────────
NODE_ENV=development                    # development | staging | production
PORT=4000                               # API server port
API_BASE_URL=http://localhost:4000      # Backend base URL
WEB_BASE_URL=http://localhost:3000      # Frontend base URL
CORS_ORIGINS=http://localhost:3000      # Comma-separated allowed origins

# ─────────────────────────────────────────────
# DATABASE (PostgreSQL)
# ─────────────────────────────────────────────
DATABASE_URL=postgresql://user:password@localhost:5432/bookmyturf?schema=public

# ─────────────────────────────────────────────
# REDIS (Cache, Sessions, Rate Limiting)
# ─────────────────────────────────────────────
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_PASSWORD=                         # Empty for local dev

# ─────────────────────────────────────────────
# JWT AUTHENTICATION
# ─────────────────────────────────────────────
JWT_ACCESS_SECRET=your-access-secret-min-32-chars
JWT_REFRESH_SECRET=your-refresh-secret-min-32-chars
JWT_ACCESS_EXPIRY=15m                   # 15 minutes
JWT_REFRESH_EXPIRY=7d                   # 7 days

# ─────────────────────────────────────────────
# GOOGLE OAUTH
# ─────────────────────────────────────────────
GOOGLE_CLIENT_ID=xxx.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=GOCSPX-xxx
GOOGLE_CALLBACK_URL=http://localhost:4000/v1/auth/google/callback

# ─────────────────────────────────────────────
# OTP PROVIDER
# ─────────────────────────────────────────────
OTP_PROVIDER=dev                        # dev | msg91 (dev: logs OTP to console, accepts 123456)
OTP_API_KEY=your-otp-api-key            # Required for msg91
OTP_SENDER_ID=BKTURF
OTP_TEMPLATE_ID=your-template-id        # Required for msg91
OTP_EXPIRY_MINUTES=10

# ─────────────────────────────────────────────
# RAZORPAY (Payments)
# ─────────────────────────────────────────────
RAZORPAY_KEY_ID=rzp_test_xxx
RAZORPAY_KEY_SECRET=your-razorpay-secret
RAZORPAY_WEBHOOK_SECRET=your-webhook-secret

# ─────────────────────────────────────────────
# AWS S3 (File Uploads)
# ─────────────────────────────────────────────
UPLOAD_PROVIDER=dev                     # dev | s3 (dev: local files, s3: presigned URLs)
AWS_REGION=ap-south-1
AWS_S3_BUCKET=bookmyturf-assets
AWS_ACCESS_KEY_ID=AKIA...               # Use IAM role in production instead
AWS_SECRET_ACCESS_KEY=xxx
AWS_CLOUDFRONT_URL=https://cdn.bookmyturf.in

# ─────────────────────────────────────────────
# WHATSAPP (Notifications)
# ─────────────────────────────────────────────
WHATSAPP_PROVIDER=interakt             # interakt | wati | gupshup
WHATSAPP_API_KEY=your-whatsapp-api-key
WHATSAPP_API_URL=https://api.interakt.ai/v1

# ─────────────────────────────────────────────
# EMAIL (Notifications)
# ─────────────────────────────────────────────
EMAIL_PROVIDER=resend                   # resend | ses
RESEND_API_KEY=re_xxx
EMAIL_FROM=BookMyTurf <noreply@bookmyturf.in>

# ─────────────────────────────────────────────
# SENTRY (Error Tracking)
# ─────────────────────────────────────────────
SENTRY_DSN=https://xxx@sentry.io/xxx

# ─────────────────────────────────────────────
# RATE LIMITING
# ─────────────────────────────────────────────
THROTTLE_TTL=60                         # Time window in seconds
THROTTLE_LIMIT=100                      # Max requests per window

# ─────────────────────────────────────────────
# BOOKING CONFIGURATION
# ─────────────────────────────────────────────
BOOKING_HOLD_MINUTES=10                 # Slot hold duration for online bookings
TRIAL_DAYS=14                           # Free trial duration for new tenants
```

## Production Notes

| Concern                | Solution                                                      |
| ---------------------- | ------------------------------------------------------------- |
| Secret storage         | AWS Secrets Manager (not .env files in production)            |
| Key rotation           | Rotate JWT secrets, Razorpay keys via Secrets Manager         |
| IAM for S3             | Use App Runner IAM role (not AWS_ACCESS_KEY_ID) in production |
| Environment separation | Separate secrets per environment (dev/staging/prod)           |
| CI/CD secrets          | GitHub Secrets for deployment credentials                     |
